# Sorry Twin — Capybara Website 🦫🤎

A small multi-page apology website made with HTML, CSS and JavaScript.

## Pages
- `index.html` — Home
- `letter.html` — A personal apology letter
- `reasons.html` — Why your friend matters
- `promise.html` — Your promise: "Ithuku aprm ippadi panna matten"
- `forgive.html` — A gentle forgiveness page

## Publish with GitHub Pages
1. Create a **public** GitHub repository.
2. Upload all files in this folder (not just the ZIP).
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then Save.
6. Your site will be at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
